Adversarial review (first draft)

review-adversarial-general.md

Verdict as written: "The PRD is well-structured and honest about assumptions, but the two things a CI user depends on most (exit code and 'secrets never leak') are specified by mutually contradictory ACs, and several absolute claims ('byte-identical', 'zero network', 'every string escaped') are verified by a single example test; the determinism/Replay caveats in §4.6/§5 are undercut by §1, UJ-2 and UJ-3." All critical and high findings below are resolved in the final PRD; see review-rubric.md "Resolution of prior findings".

critical

Exit code for error unresolvable from the Status model

FR-27, AC-27.2, AC-21.3
Status carried no cause; five concrete Suites yielded two or three candidate codes each.
Fix: Resolved: AC-27.3 and AC-27.4 define execution failure versus evaluation error and a full precedence.
critical

Redaction ACs promised value-based secrecy while the FR was key-based at write time

FR-31, AC-31.3, AC-28.2, AC-19.2
A secret in free-text Final Output could not be caught; live and Replay evaluated different Traces.
Fix: Resolved: Redaction at Trace ingress, key-based plus declared environment values, limits documented.
high

skipped unreachable; all-skipped turned CI green

AC-18.1, AC-18.2, FR-27
A renamed Trace directory produced all-skipped Scenarios and exit 0.
Fix: Resolved: two named producers; zero-evaluation run exits 1 (AC-18.5).

Fix: Resolved: Capture declaration (AC-5.6, AC-12.4, AC-21.5).
