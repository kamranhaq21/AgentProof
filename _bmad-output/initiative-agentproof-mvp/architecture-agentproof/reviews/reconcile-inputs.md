# Reconcile inputs against the architecture spine

Spine: `architecture-agentproof.md` (AD-1..AD-18) and `adr-log.md`, both dated 2026-10-22.
Inputs: PRD (FR-1..FR-35, AC-n.m, NFR-1..NFR-10, OQ-1..OQ-19), `PROJECT_SPEC.md` §6.1, §6.3, §6.5, §6.9, §7, §8, §9, §10, §11, §12, §13, the PRD addendum §B/§C, and the user's nine bullets.
Format: `[source] quoted phrase — gap — suggested resolution — severity (high / medium / low)`.

Verdict on the user's "schemas" ask: the spine fixes the model *configuration* (frozen, forbid, strict, integer `version`), the event identity (`seq`), the Final Output location, the Status enum, `JsonValue`, the date format, and the redaction block. It does not fix the field list of any artifact. Two independent builders would agree on how a Suite, Trace, or Report is validated but not on what is in one. See the first item below.

## Contradictions

- [AC-18.1 vs AD-6] "`skipped` if every Assertion skipped, otherwise `passed`. Suite Status uses the same precedence over Scenario Statuses" — AD-6's fold `failed > error > skipped > passed` makes a Suite with one skipped Scenario and nine passed ones `skipped`; the PRD makes it `passed`. Exit code is unaffected (0 either way) but the Report's Suite Status differs. — Fix AD-6: `combine` = `failed` if any failed; else `error` if any error; else `skipped` if all skipped; else `passed` — high.
- [AD-2 vs AD-9 vs AD-14 vs structural seed] "`adapters` and `redaction` import `models` and `errors` only" — `Adapter.run(scenario, context: RunContext)` references `RunContext`, which the seed places in `runner/context.py`, a layer above `adapters`; `RunContext` carries a `logger` and `output_dir`, which a frozen strict Pydantic model cannot hold without `arbitrary_types_allowed`; the Fixture Agent must parse a Trace JSON file, which needs `loading` (forbidden) and the filesystem (AD-1 places `adapters` in neither core nor shell). import-linter as specified would fail on the reference design. — Fix: `RunContext` is a frozen dataclass in `adapters/protocol.py` (or `models/context.py`); declare `adapters` shell and allow it to import `models`, `errors`, `loading`, `io` — high.
- [AD-8 vs AD-2] "the Suite model's `assertions` field is a discriminated union built from the registry" — `models.suite` would import `assertions.registry`, inverting the AD-2 layer `models < assertions` and making model import order depend on `assertions.builtin` having been imported. — Fix: `models.suite.Scenario.assertions: list[AssertionConfig]` with the concrete union assembled in `loading.suite` (which may import both), or move the `AssertionConfig` subclasses into `models` — medium.
- [AC-23.6 vs AD-13] "`report` writes `<report name>.html` next to the JSON Report by default; `--output PATH` overrides" — AD-13 fixes the HTML name to `report.html` inside the Output Directory and makes `--output` a directory; `replay-<id>.report.json` has no HTML counterpart in AD-13's list, and `report --output` is a file path. — Fix AD-13: HTML name = JSON name with `.json` replaced by `.html`, next to the JSON by default; `run --output` is a directory, `report --output` is a file — medium.
- [FR-31 vs AD-10 assumption] "every occurrence of the current value of each environment variable named under `redact.env`" — AD-10 declines to scrub values shorter than 8 characters, so a short declared secret leaks while the Trace reports `redaction.applied: true`. Tagged, but it narrows a requirement rather than filling a gap, and AC-31.3's planted value could legitimately be short. — Open Decision: amend FR-31 (minimum length, skipped names recorded as `redaction.env_names_skipped`, warning printed) or drop the floor and skip only empty values — medium.
- [AC-9.2 vs AD-16] "Replay (FR-19) performs zero network calls and spawns zero subprocesses, verified ... an in-process test that makes socket creation and subprocess spawning raise" — AD-16's guard fixture is "active for all core tests"; Replay runs through `runner` and `cli` (shell), which the guard as scoped does not cover. — Fix AD-16: guard active for core tests and for `trace replay` and `run --adapter fixture` integration tests; only the exit-code subprocess harness opts out — medium.
- [FR-26 vs AD-11] "duration and cost are reported only when present on both sides" — AD-11 calls `VOLATILE_FIELDS` "the one list that `compare` excludes"; the PRD excludes them from the equality decision (AC-26.1) but wants them reported. — Fix AD-11 wording: excluded from the decision, reported informationally when present on both sides — low.
- [AC-28.1 vs Conventions "Error shape"] "no traceback unless `--verbose` is set" (malformed YAML/JSON, exit 2) — Conventions say `--verbose` appends diagnostics for exit 3 and 4 only. — Fix Conventions: `--verbose` adds diagnostics for 2, 3, and 4 — low.
- [AD-4 vs AD-1] "`python -m agentproof.models.export_schemas` ... committed" — a file-writing entry point inside `models` (core) breaks AD-1's no-filesystem rule and its lint. — Move to `scripts/export_schemas.py` or a `cli` subcommand — low.
